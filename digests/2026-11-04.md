# AI 日报 - 2026年11月04日

## 今日重点

**1. Postman 被曝静默安装 AI 插件并尝试共享所有 API 数据**

Hacker News 热帖（1053 分）指出，Postman 在未充分告知用户的情况下自动安装 AI 插件，并尝试将用户的 API 请求数据共享出去。开发者已在官方 GitHub 仓库提交 issue，引发对数据隐私的广泛担忧。

链接：https://github.com/postmanlabs/postman-app-support/issues/14370

**2. Google 被曝将切断拒绝引入 AI 的学校的搜索服务**

据《纽约时报》报道，Google 计划对拒绝采用 AI 相关安排的学校关闭搜索服务，该做法引发教育界对科技公司强制推广 AI 的争议（562 分）。

链接：https://www.nytimes.com/2026/11/03/us/google-search-schools-restrict-ai.html

**3. OpenAI 疑似静默重新启用 Codex 聊天数据训练模型**

有用户发现 OpenAI 似乎在未明确提示的情况下，重新启用对 Codex 对话内容的模型训练，相关讨论在 Hacker News 获得 437 分。

链接：https://news.ycombinator.com/item?id=50352757
