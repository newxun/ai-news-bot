**1. Claude Code 官方 VS Code 扩展被植入后门，出现在 Cursor Marketplace**
Hacker News 热度 775 分、485 条评论，为今日最热话题。多个来源报道：一个带后门的 Claude Code VS Code 扩展被上架到 Cursor Marketplace，据 DoublePulsar 报道，攻击链涉及向 Claude 开发者的笔记本植入远程访问木马（SSH 后门）。Cursor 官方已发布安全公告确认 Marketplace 中存在恶意 Claude Code 扩展。
- 分析文章：https://phorion.io/blog/offical-claude-code-vsx-compromise/

- HN 讨论：https://news.ycombinator.com/item?id=50300683

**2. AI 不是在取代 SRE，而是在让他们"去技能化"**

- 原文：https://newsletter.signoz.io/p/ai-isnt-replacing-sres-its-deskilling
