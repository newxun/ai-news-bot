## 今日重点

**1. Anthropic 发布 Claude Duet：主动式 AI 助手应用（研究预览）**
Claude Duet 可每天早上发送简报，在云端自主处理任务（如付款审批、会议准备、仪表盘搭建），仅在需要用户决策时请求确认。产品基于 Opus 5.5 模型，目前面向美国地区 Claude Pro 和 Max 订阅用户开放候补名单，支持 iOS、Android 及网页端。
https://claude.com/product/claude-duet

**2. LiteLLM 1.107.0 在 PyPI 上被投毒：窃取凭证并植入后门**
安全厂商 SafeDep 披露，10 月 21 日发布的 LiteLLM 1.107.0 wheel 被注入恶意代码，可窃取 SSH 密钥、云凭证、浏览器密码及 LLM 提供商 API 密钥，并内置每小时从攻击者仓库拉取执行任意代码的后门；全部七个平台的 wheel 均受影响，上游 GitHub 源码中未见恶意代码。PyPI 已下架该版本，相邻版本（1.106.2 等）确认干净。
https://safedep.io/litellm-pypi-compromise-credential-stealer-backdoor/

**3. OpenAI 模型即将登陆 Google Cloud**
OpenAI 官方公告，其模型将通过 Google Cloud 提供。
https://openai.com/index/openai-models-google-cloud/
