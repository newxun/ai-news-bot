**1. Claude 系列服务出现登录认证故障，现已恢复**

据 Claude 官方状态页，11月13日 09:58 UTC 起 claude.ai 与 Claude Code 出现用户认证错误，影响范围包括 claude.ai、Claude Console（platform.claude.com）、Claude Code 与 Claude Cowork。11:05 UTC 部署修复并进入监控，11:58 UTC 官方确认问题已解决。该事件在 Hacker News 引发大量讨论，相关帖子最高获 484 分。

**2. OpenAI 解散独立机器人团队**

据 Fortune 11月13日报道，OpenAI 已解散独立的机器人团队，并将该团队研究人员重新分配至公司其他部门。OpenAI 表示此举是为了加速机器人技术进展而非放弃该方向，公司希望其通用模型能够直接控制机器人。

- 原文：https://fortune.com/2026/11/13/openai-disbands-robotics-team-as-its-general-models-start-running-robots/
- HN 讨论：https://news.ycombinator.com/item?id=50487184

**3. AI 帮助解读哥德尔笔记本，据称含数百条已证明定理**

据《卫报》11月13日报道，研究人员借助 AI 解读数学家库尔特·哥德尔的笔记本，据称其中包含数百条已被证明的定理。

- 原文：https://www.theguardian.com/science/2026/nov/13/kurt-godel-notebooks-ai-helps-unlock-hidden-discoveries-man-who-transformed-maths
