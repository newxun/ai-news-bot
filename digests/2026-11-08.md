### Claude Code「Don't Ask Again」导致密码泄露至 1122 个公开 GitHub 文件
安全研究机构 Apiiro 报告，开发者在 AI 编码代理请求授权时点击「不再询问」，可能导致敏感凭据被写入提交历史。研究团队在 1122 个公开 GitHub 文件中发现了泄露的密码等秘密，提示 AI 编码工具的权限管理存在安全风险（178 分，125 条评论）。
- 原文：https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again
- 讨论：https://news.ycombinator.com/item?id=50407882

### Anthropic 发布 Agent 记忆组件研究
Anthropic 发表研究文章《The Components of Agent Memory》，拆解智能体记忆系统的组成部分，探讨 Agent 如何在长期任务中存储与调用记忆（151 分，79 条评论）。
- 原文：https://www.anthropic.com/research/components-of-agent-memory
- 讨论：https://news.ycombinator.com/item?id=50402212
