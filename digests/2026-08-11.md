# AI 日报 - 2026年8月11日

## 今日重点

### Meta 发布 Muse Glimmer：30B 参数的本地代理模型
Meta 推出 Muse Glimmer，这是一个 300 亿参数的开放模型，专为本地设备上的持续代理工作流优化。该模型旨在在边缘设备上实现高效的 AI 代理功能。
https://research.meta.ai/blog/introducing-muse-glimmer-open-agentic-model

### Docker 推出 AI 代理沙盒功能
Docker 发布 Docker Sandboxes，为 AI 代理提供一次性、隔离的沙盒环境。这一功能旨在让 AI 代理能够安全地执行任务而不会影响主机系统。
https://www.docker.com/products/docker-sandboxes/

### Claude Code 自动模式成为默认设置
Anthropic 宣布 Claude Code 的自动模式现在对所有用户默认开启。自动模式让 Claude 能够更自主地执行任务，而无需用户频繁确认。
https://claude.com/blog/auto-mode-default-in-claude-code
