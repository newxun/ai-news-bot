# AI 日报 - 2026年11月27日

## 今日重点

**1. AI 让自托管重新变得有趣**（Hacker News 429 分）
作者 Jan-Lukas Else 分享：把基础设施配置（Docker Compose、脚本等）放进 Git 仓库后，可以用 AI 编码代理像对待普通软件项目一样维护家庭服务器，大幅降低了尝试新服务的门槛，让沉寂已久的自托管热情重新回归。
- 原文：https://janlukas.blog/posts/ai-self-hosting
- 讨论：https://news.ycombinator.com/item?id=50660180

**2. 分析称 OpenAI 可能已进入"成本控制模式"**（Hacker News 304 分）
micjm.com 基于其对战系统的数据显示，OpenAI 新发布的 Astra 6.2 与 Sol 6.2 相比上一代模型，每任务输出 token 和推理 token 数量显著下降（统计上显著），作者据此推断新模型是围绕节省成本进行的调优。
- 原文：https://micjm.com/blog/openai-is-in-cost-control-mode/
- 讨论：https://news.ycombinator.com/item?id=50652527

**3. Google 将要求 AI Agent 使用其 Workspace MCP 服务器**（Hacker News 282 分）
11 月 24 日 Google 将 8 个 Workspace MCP 服务器正式发布（GA），并在 API 条款中新增条款：自 2027 年 2 月 1 日起，"由 AI Agent 驱动"的工具必须通过这些 MCP 服务器访问 Gmail、Drive、Calendar 等服务。目前 Gmail MCP 只能搜索邮件、读取会话、创建草稿和打标签，不能发送、回复或转发邮件，发送类工具需"合作伙伴访问权限"。
- 原文：https://techstackups.com/articles/google-workspace-ai-agents-mcp/
- 讨论：https://news.ycombinator.com/item?id=50653477
